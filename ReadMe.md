# 🔐 Password Manager

A simple and secure password manager that lets you store, view, and manage your passwords directly in your browser using local storage.  
Designed with a clean UI and a practical layout for quick access.

## 🧩 Features

- 🧠 Stores website logins in localStorage
- 🕵️‍♀️ Passwords hidden with bullet masking (•)
- 📋 One-click copy for website, username, or password
- 🗑️ Delete any saved password instantly
- 🖥️ Responsive and minimal UI
- 💾 Automatically updates on every add or delete
